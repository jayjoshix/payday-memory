## Reproduce locally

Start the app at `http://127.0.0.1:4173`, then run:

```sh
npm run demo:record -- --check-flow
npm run demo:record
python scripts/encode-captioned-demo.py --startup-seconds 2.6
```

`demo:record` and `demo:record:captioned` use the same captioned recorder. The recorder uses the installed Playwright browser/encoder. The encoding and frame-check helper uses local Pillow and the existing Playwright FFmpeg executable. Review a new capture's startup before reusing the 2.6-second offset. No sponsor call or paid service is needed for this captured-proof flow.

Record the real application in a clean browser context. Keep the viewport fixed; take full-page documentation screenshots in a separate context. Inspect readable amounts, captions, correction results and provenance before publishing. Never show credentials or describe an unperformed action as complete.

The 167.96-second uncut source stays at `docs/demo/payday-memory-submission-uncut.webm` locally and is excluded from Git. It can be regenerated by the recording command. Public recording metadata retains its original source path and hash as provenance; that path is not a bundled GitHub asset.
